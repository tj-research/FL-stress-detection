# FL-stress-detection
Dataset used for the experiment downloaded from this link: https://www.kaggle.com/datasets/orvile/wesad-wearable-stress-affect-detection-dataset

FedAvg_WESAD_Baseline+Defense.py contains subject-independent evaluation and defense mechanisms. 

FedAvg_WESAD_subject_depend.py contains subject-dependent evaluation.

Inference_Attacks.py contains the attacks (Reported Membership and Label Inference Attacks).
